# ALICE // CLOCKWORK SKY

不思議の国のアリスをモチーフにした、グラディウス風2D横スクロールシューティングです。Unityネイティブ版と、依存パッケージ不要のWeb版を同梱しています。両版は別実装のため、対応する入力と表示機能が一部異なります。

## Unity版（推奨）

1. Unity Hubからこのフォルダを **Unity 2022.3.62f1** として開きます。
2. `Assets/Scenes/ClockworkSky.unity` を開いて **Play** を押します。カメラ・背景・ゲーム本体・HUDを自動で生成します。
3. このシーンは *Scenes In Build* にあらかじめ登録済みなので、そのままスタンドアロンビルドできます。

`Assets/Scripts/ClockworkSkyGame.cs` が、プレイヤー、敵・ボス、パワー、弾、衝突、設定、ローカル記録、Unity UIを含む自己完結したゲーム本体です。外部画像・プレハブは不要です。

### Unity版の操作

| 操作 | キーボード / マウス | モバイルタッチ |
| --- | --- | --- |
| 移動 | `WASD` / 矢印キー | 画面左側をドラッグ |
| ショット | `Space` / `J` / 左クリック（長押し可） | 画面右側を押す |
| パワー発動 | `Shift` / `K` | 非対応 |
| 一時停止 | `P` / `Esc` | 非対応 |

Unity版にはゲームパッド入力とゲーム内フルスクリーン切替はありません。表示モードはビルド時のPlayer Settingsまたは起動時のプラットフォーム設定で管理してください。

## Web版

### 前提と起動

`index.html` をブラウザで開くか、ローカルサーバーを起動します。

```powershell
npm run serve
```

その後 `http://localhost:8080` を開いてください。

`npm run serve` にはPATH上のPythonが必要です。Web版の構文チェックにはNode.jsを使います。依存パッケージがないため、どちらも `npm install` は不要です。

### Web版の操作

| 操作 | キーボード | 画面ボタン | ゲームパッド |
| --- | --- | --- | --- |
| 移動 | `WASD` / 矢印キー | 方向ボタン | 左スティック |
| ショット | `Space` / `J`（長押し可） | `FIRE` | Button 0 |
| パワー発動 | `Shift` / `K` | `POWER` | Button 1 |
| 一時停止 | `P` / `Esc` | 一時停止ボタン | Button 9 / Menu |

Web版の設定画面からブラウザのフルスクリーン表示を切り替えられます。ブラウザや端末によってはFullscreen APIが利用できません。

## 実装済みの内容

- アリス・クラフト、カード兵、時計うさぎ、ティーポット、チェシャ猫、赤の女王のオリジナル図形表現
- 1ステージのウェーブ進行、ボス戦、勝利・ゲームオーバー・再挑戦フロー
- 6段パワーメーター、スピード・ミサイル・ダブル・レーザー・オプション・シールド
- 残機、無敵時間、シールド、弾幕、かすりボーナス、スコア、ベストスコア、記念品（実績）
- ポーズ、音、画面揺れと、版ごとのキーボード／タッチ入力
- ローカル永続化された設定とハイスコア、低モーション、高コントラスト、キーボードフォーカス、ライブ通知
- Unity版: 依存しないランタイム生成、PlayerPrefs永続化、生成音、Unity IMGUIのメニュー/HUD
- Web版: ゲームパッド、Fullscreen API、依存関係なしの静的配布と構文チェック用 `npm run check`

## 保存データとプライバシー

- Unity版はベストスコア、記念品、サウンド・画面揺れ・アクセシビリティ設定を端末のPlayerPrefsへ保存します。
- Web版はベストスコア、記念品と設定をブラウザのlocalStorageへ保存します。
- アカウント、分析、クラウド保存、外部サービスへの送信は実装していません。保存領域を消去すると記録と設定も失われます。

## 開発時チェック

Web版はNode.jsで構文を確認します。

```powershell
npm run check
```

Unity版は `Assets/Scenes/ClockworkSky.unity` をPlayして主要フローを確認した後、対象プラットフォームのPlayer buildでも入力と保存を確認してください。
